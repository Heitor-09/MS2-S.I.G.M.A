# 🚀 MS2 - S.I.G.M.A

Aplicação web moderna, limpa e responsiva desenvolvida com HTML, CSS customizado e Bootstrap.

---

## 📌 Sobre o Projeto

O **S.I.G.M.A** é um projeto de interface web focada em usabilidade, design centralizado e responsividade. Utiliza a estrutura flexível do Bootstrap combinada com estilos CSS personalizados (como componentes 3D interativos e alinhamentos automáticos).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** - Estruturação semântica das páginas.
* **CSS3** - Layout Flexbox, personalização e efeitos visuais.
* **Bootstrap 5** - Framework para estilização e componentes responsivos.
* **Node.js / npm** - Gerenciamento de pacotes do projeto.
* **Git & GitHub** - Controle de versão e desenvolvimento colaborativo.

---
